## 执行约束

- 先落盘发现和计划，再修改实现。每项新增回归必须验证用户可见语义或领域边界，避免只测试代码长相。
- 先运行有针对性的测试；变更收敛后统一执行 `npm run check`、`npm run audit:prod`、`npm run check:smoke`。失败先判断实现还是历史测试契约，不删测试绕过失败。
- 内容修改经过 `content:prepare` / `validate`，不手工编辑生成产物。保留学习 ID、备份格式及原有资产。
- 浏览器使用隔离测试上下文，避免覆盖用户学习记录。以最终构建做视觉和操作验证，预览恢复至 3001。
- 交付报告明确自动验收覆盖范围及母语教学审校、真实学习成效实验的边界；不能用“全绿”替代这些外部证据。

### 实际修复

- A01：Next / eslint-config-next 16.3.3、sharp 0.35.4、baseline-browser-mapping 2.11.0；同时更新开发工具链的 4 个受影响包，未变更审计阈值。
- A02–A03：新增纯播放策略；翻译、填空与主动输入答题前隐藏答案声；真实播放开始才允许答题，超时进入失败，重试使用独立请求标识隔离迟到回调。键盘与按钮共用提交守卫。
- A04：两个近同音项目使用语义或构字条件，真正听辨保留对比双方；字母题明确声音位置并排除合流干扰项；复习生成器、历史错题和能力事件都适配拼写证据，保留原 ID。
- A05：复述和输出自动评分明确核对归档原句；目标改写不再接受原草稿；历史输出错题也移除旧草稿备选答案。
- A06：全题覆盖、去重和总分核验进入领域函数；缺题或重复题成绩为 0；无答题记录不能推进掌握或学习连续天数；正常录音/输出前置和存储回滚继续有效。
- A07：连音、流音化、ㅎ 脱落、腭化补充边界与例外；ㅚ/ㅟ 说明修正，组合字形与双元音概念分开。
- A08：各语法生成器使用译句干扰项；联系一词区分名词/动词；语用复习沿用作者提供的专门干扰项。
- A09：所有站内普通链接经共享 StudioLink 保持整合视图和深链；空复习去重、去掉全零统计；内部英文标签换成中文说明。
- A10：全仓 TS strict 开启；空值、课程查找、动态索引和语音设置都有明确类型。没有用新增 any 或非空断言压制这些错误。
- A11：中文 404 与错误边界；动态块加载失败以完整页面重载恢复，避免同路径错误边界滞留。导航规则的单行 lint 例外有明确原因和故障注入回归。
