# 教材与听读任务核对 · 2026-09-12

本记录是本轮产品审计的内容附录。核对对象为课程正文中的构字、双收音、ㄹ 发音与词性说明，以及全部 29 份听读材料的 87 个复述提示、输出任务和情境连续性。它不代替 722 个词条的逐条母语教师审校，也不证明课程难度已经通过学习者实验标定。

## 教材修正

| 修复前问题 | 修正 | 位置 |

双收音及其后续条件依据[国立国语院《标准发音法》](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0002)第 10–14 条。共十一个双收音还可在[国立国语院《바른 국어 생활》2016 教材](https://www.korean.go.kr/common/download.do?c_file_name=c0cbf5a7-cb03-4e25-9a43-f2f44b4e382a_0.pdf&file_path=etcData&o_file_name=%5B%EA%B5%AD%EB%A6%BD%EA%B5%AD%EC%96%B4%EC%9B%90%5D+%EB%B0%94%EB%A5%B8+%EA%B5%AD%EC%96%B4+%EC%83%9D%ED%99%9C+%EA%B5%90%EC%9E%AC_2016.pdf)第 69 页核对。

ㄹ 的初声/元音间闪音与终声/停顿前边音区别，见[国立国语院 2017 年国际通用韩国语标准课程研究](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=45&pageIndex=1&report_seq=932)附件第 123 页；例子为 불 与 부리。만들다 的词性为动词，见[韩国语基础词典词条](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=60317&blockCount=10&currentPage=1&exaType=&mainSearchWord=%EB%81%9D&nation=jpn&nationCode=7&proverbType=&searchType=E&sort=W&viewType=A&wordMatchFlag=N)。本次使用官方网页检索内容核对，未把词条或教材整页复制进应用。

## 验证与边界

- 内容修复后 `npm run validate` 通过：60 课、722 词、83 语法点、5 组韩文、29 份材料。生成运行时与作者源一致；首页变更涉及的旧文案断言已在集成时同步。最终完整验收以主报告为准。
- 定向内容、课程路线、材料前置测试共 24 项通过。新增正文构字负例能抓出错误字母组合，双收音目录检查覆盖十一个合法项目。
- 本轮未改变材料 ID、前置课 ID、韩语音频文本或评分阈值；课程首课标题变更同步到生成数据。
- 全量 UI、学习保存和视觉回归由本轮产品审计统一执行；本附录不将定向测试冒充完整发布验收。

这些修正提升教材的内部一致性和任务可回答性。自然度、韵律与真实学习效果仍需母语教师及学习者验证。
