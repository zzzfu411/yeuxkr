# Kirina Korean 文案语气与术语

界面像一位懂韩语、愿意陪练的老师：说清楚现在要做什么、为什么做、做完会发生什么。语气平静、具体，不用后台实现词汇冒充学习指导。

## 一句话原则

先说动作，再补原因。一个句子只承担一件事。

## 面向学习者的术语

| 避免直接展示 | 优先写法 | 说明 |
|---|---|---|
| 核心路径 | 主线课程 | “路径”可作导航名，不用来描述数据写入 |
| 图书馆门槛 | 内容基础 / 还需学习 | 直接列出缺少的韩文、词汇、语法或材料 |
| 证据、证据链、证据闸门 | 学习记录、完成条件、阶段检查 | 只有安全、审计语境才使用“证据” |
| 写入、回写 | 保存、计入 | 写清保存到进度、复习或作品集中的哪一处 |
| 闭环、回流 | 完成这一轮 / 加入复习 | 不向学习者暴露流程图术语 |
| 迁移 | 综合运用 / 换个场景再用 | 只有教学解释确实需要时才保留“迁移” |
| SRS | 间隔复习 | 第一次可写“间隔复习（SRS）”，之后只写“复习” |
| 真实材料 | 情境听读 / 自编情境材料 | 站内材料是自编脚本和系统语音，不能暗示原生录音 |
| 母语者层、母语者表达 | 自然表达 / 进阶表达 | 接近母语者是长期目标，不是站内等级 |
| 能力护照 | 学习进度 | 站内分数不是 CEFR 认证 |
| 记忆债、错题债 | 到期复习、待重练错题 | 不用带惩罚感的比喻 |
| 伪装成完成 | 不计为完成 | 描述规则，不指责学习者 |

代码中的字段名、类型名和存储键可继续使用内部术语；本表约束的是用户会看到的文字。

## 句子写法

- 按“动作 → 结果”组织。例如：“先完成第 8 课。达标后，这段听读会解锁。”
- 错误提示保留三件事：发生了什么、当前内容是否还在、下一步怎么做。
- 按钮尽量写动作：“加入复习”“继续第 12 课”“保存作品”。
- 空状态不要解释系统架构。告诉学习者怎样让内容出现。
- 不用“新的学习模型”“能力迁移地图”“推进器”等宣传或抽象比喻。
- 页面开头最多保留一个主张和一个说明段；相同规则不要在首屏重复三遍。
- 英文只作纸本批注。计数与状态用中文，不出现 “shown”“level/category”“min” 等实现痕迹。
- 不用第三人称“用户”。直接说“你”，或省略主语。

## 真实性边界

- 站内听读是自编韩语脚本，由预生成音频或设备语音播放。没有原生录音时，不写“原声”“真实语速”。
- A0、A1、A2、B1-B2 只表示站内进度参照，不是考试成绩或 CEFR 认证。
- 60 节课程提供从入门到中级过渡的练习，不承诺 C1、C2 或母语者水平。
- 本地进度可由学习者修改，只适合个人学习反馈，不代表资质或授权。

## 交付前自检

1. 学习者能否在五秒内看懂下一步？
2. 是否有“证据、闭环、迁移、写入、门槛”等可换成日常说法的词？
3. 同一屏是否重复解释了同一规则？
4. 是否暗示了原生材料、正式等级或站内并不具备的能力？
5. 大声读一遍，像老师在说话，还是像产品需求文档？
