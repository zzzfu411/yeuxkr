# 散落在页角的韩文字小图片

本文保留文字资产与此前布局的演变记录。当前首页采用学习笺构图和开放的文字目录，执行规范以 [learning-note-home.md](learning-note-home.md) 为准，下方双栏方案不再使用。

## 本轮方向

### 最新结构修正：内容决定高度，入口进入首屏

用户指出整页留白过多。本次调整版式结构：取消首页 520/550px 最小高度和手机 120px/105px 装饰留空，删除占据 150–180px 的独立页尾标语。桌面使用左侧学习标题、说明与主按钮，右侧纵排两个内容入口的紧凑双栏；手机按标题、按钮、两个入口顺序自然排布。入口无需向下滚动一整屏才能出现。

颜色沿用纸白 #FCFCFA、墨黑 #222222、钴蓝 #3155E7、柠檬黄 #F2EB98、橘红 #FF784F、淡紫 #D8CCF0。系统 sans 用于标题、正文与控件，韩语阅读字体不变。两栏均左对齐；标题约 36–56px，区块间距 24–56px，图片仅作为靠近内容的 34–140px 小贴片，不撑开版面。

把韩语，         안녕       课程、字词与听说

Kirina Korean            每天一点，慢慢听懂。

复核：仅缩小四周间距会保留原来“先看大标题、再向下找入口”的结构，因此直接将入口与主学习动作并排。继续保持贴片大小、角度和密度不同；页尾文案由已有网站页脚承担。以下方案保留为历史记录。

实施与验收：手机首屏区域由约 550px 收紧至 279px；390px 宽度下两个入口的底边分别位于页面 502px 和 612px，均在首屏内。1440px 宽度下入口与标题并排，底边位于 258px 和 406px。移除了独立标语区及首页容器的剩余高度拉伸。320px 下进一步缩小并下移한글贴片，避开预计用时文字。已检查桌面、平板与手机截图；内容校验、ESLint、生产构建通过，九个栏目、六种宽度下的 30 个布局组合及材料导航/草稿恢复回归通过。PWA 截图已同步；最新截图为 output/playwright/compact-home-wide.png 和 compact-home-narrow.png。

### 最新摆放修正：疏密不均，取消四角呼应

用户认为四角均匀分布过于刻意。本次复用六种透明素材，色彩保持纸白 #FCFCFA、墨黑 #222222、钴蓝 #3155E7、柠檬黄 #F2EB98、橘红 #FF784F、淡紫 #D8CCF0；字体仍为系统 sans 与韩语阅读用 Noto Serif KR。主文案居中，学习内容左对齐。

首屏只放三枚：左上偏内是一大一小的안녕/ㅋ组合，另一枚한글靠下偏右；其余角落留空。手机把小组合放在文案前，落单短词放在按钮后偏左。两个入口贴片的高度、大小不同，页尾只留一个靠近文字的ㅎ。内页装饰改成局部聚拢的小组合。位置静态设定，不在刷新时随机跳动。

```text

          ㅋ        把韩语，
                    学进日常。

    学一点新的              把学过的记牢
                                       다시

```

复核：仅改变旋转角度仍会保留四角框架，因此先撤去首屏的ㅎ和页尾的ㅋ，再用局部疏密、大小差异与错位打破平均分配。艺术可有松散感，正文、导航与触控区继续保持清晰稳定。以下四角方案保留为上一轮记录。

本轮实现已完成。已逐张检查 1440 / 390 / 320px 首页以及手机学习、练习页：首屏三枚贴片不再围成四角，局部组合与文字保持可读间距，按钮没有遮挡。内容校验、ESLint、生产构建通过；九个栏目与六种宽度下的 30 个布局组合回归通过，材料历史导航和草稿恢复正常。生产预览为 http://127.0.0.1:3001/，PWA 截图同步更新。最新截图见 output/playwright/loose-home-wide.png 与 loose-home-narrow.png。

按用户明确修正，只使用单个或几个韩文字组成的小图片。每张图是一个独立贴片，周围透明，可以分散在标题旁、栏目边缘与页角。照片和完整拼贴退出页面内容区。

## 设计计划与复核

- 色彩：纸白 #FCFCFA、墨黑 #222222、钴蓝 #3155E7、柠檬黄 #F2EB98、橘红 #FF784F、淡紫 #D8CCF0。
- 字体：正文与控件沿用系统 sans，韩语阅读保留 Noto Serif KR；图片内文字采用粗体韩文印刷字。
- 层级：主标题居中成为视觉中心，贴片只有 60–170 CSS px，不与主按钮争夺注意力。每个模块通常只用一枚短词和一枚单字母。
- 对齐：首页主文案居中；课程、设置与操作表单继续左对齐。装饰绝对定位于所在区块，不固定在视口中。
- 手机：贴片重新分布在文案上方两角与按钮下方留白中，触控区和文本不被遮挡。
- 动效：不漂浮、不跟随鼠标、不自动旋转；少量静态倾斜制造随手贴上的感觉。

```text
Kirina                今日 学习 练习             我的

                     把韩语，
                     学进日常。
                    说明 + 学习按钮

      ㅎ          한 글자부터, 천천히.             ㅋ
```

设计复核：把原来的封面容器撤掉，文字贴片是独立图片节点，各自控制大小、位置与角度。保留上一轮三个导航入口、近期六课和所有学习逻辑。
