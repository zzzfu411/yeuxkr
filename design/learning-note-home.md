# 首页再设计：一张韩语学习笺

## 截图复核

用户提供的截图显示，上一版只是把内容从左右移到中间：黑体标题压缩过紧、蓝色按钮过强、学习用时重复，两个框格入口仍然像表格。图片与字没有组成一个主体；只有对齐和无溢出不足以完成视觉验收。

## 本轮方案

最新微调：按用户要求在内容区左上角加入柠檬黄 ㅎ，右上角加入钴蓝 한글。左侧较小且靠上，右侧稍大、稍低，角度相反；中央安녕仍是主视觉。沿用本方案的色彩与字体，不增加装饰占位。手机分别缩到 48px 和 70px，避开导航与中央词片。

角落微调验收：直接检查 1440、656、481、390、320px 截图。481px 初稿的右侧词片靠近中央 ㅋ，增加 600px 断点缩小、上移后复查；手机左上贴片与导航保留间距。生产构建和 ESLint 通过，图片加载、无横向溢出、装饰不拦截首页链接检查通过。最新截图为 `output/playwright/corners-home-*.png`。

```text
       ㅎ                         한글
                    안녕
                       ㅋ
```

- 色彩：纸白 #FCFCFA、正文 #222222、钴蓝 #3155E7、淡紫 #D8CCF0、橘红 #FF784F、柠檬黄 #F2EB98。大面积保持纸白，颜色由韩文字碎片承担。
- 字体：中文优先 Noto Sans SC / PingFang SC / Microsoft YaHei，标题 32–40px、450 字重、正常字距，正文 14px。品牌继续使用紧凑的拉丁 sans。消除黑体压扁的海报字效果。
- 构图：内容宽度约 600px，顶部安녕字片组成唯一的视觉焦点；标题改为一句话，下面是单行说明和一个克制的主操作。学习与练习是无外框的两行目录，不再切成相同卡片。
- 对齐：整页主体居中，主文案与动作居中；目录标题和说明左对齐，右侧只保留方向提示。文字碎片与目录局部交叠，但不覆盖内容。
- 导航：去掉首页选中项的大色块，保留细小标识和完整触控范围；页脚只保留安静的品牌署名，不重复口号。
- 响应式：320px 下缩小标题，空间不足时按短句换行；接近用户截图的 656px 宽度单独检查，不沿用宽屏和手机截图推断中间尺寸。

```text
       Kirina           今日 学习 练习        我的

                         안녕
                              ㅋ
                 把韩语，学进日常。
                看懂一个字，听懂一句问候。
                     [开始学习]

          조금씩    学一点新的     课程、字词与听说  ↗
                    把学过的记牢   复习、错题与测验  ↗
                                                    다시

                         Kirina Korean
```

## 实现前自审

单纯缩小标题和卡片仍会保留原来的模板结构，因此取消外框与中间分栏，将两个入口改为短目录。韩文短词是页面的主视觉，中文承担清楚的功能引导；不新增装饰标签、数字编号或学习功能。首访和回访推荐继续使用现有 workspace，图片保留透明、不可交互、对读屏隐藏。

视觉验收需直接查看截图，判断标题/图片/按钮的权重、各元素的连续关系及重复信息；功能检查另外记录，不把自动检查结果等同于美感结论。

## 实现后复核

已直接查看 320、390、656、768、1440px 宽度的画面，以及白昼、蓝调、暖阳和夜行四种主题。656×687 CSS 像素、1.5 倍像素比用于接近用户截图的窗口比例。第一轮截图中手机的 조금씩 过于贴边，第二轮缩小并移回内容区；开放目录也从 600px 收到最大 520px，减少入口标题与说明之间的空隙。

最终图形的权重按韩文短词、中文标题、主操作排列；中文从 650 字重和负字距的两行标题改为 450 字重的一句话，按钮缩到 132×44px，三分钟只表达一次。两行入口去掉外框，页脚移除重复口号。宽屏仍保留开放背景，主体内容没有按窗口高度拉伸。

生产截图：`output/playwright/note-home-reference.png`（接近用户截图比例）、`note-home-wide.png`、`note-home-narrow.png`；宽屏与手机图同步到 `public/assets/screenshots/`。这是本轮实际实现的记录，不代表用户已认可视觉方案。

功能验证：内容校验、ESLint、生产构建含 TypeScript 通过；九个栏目、六种宽度共 30 组布局、材料导航与草稿恢复回归通过。生产预览的三个首页入口、键盘焦点与 Enter 跳转、装饰图加载也通过。保留一个 h1、三个主导航目标和至少 44px 的主操作高度。
