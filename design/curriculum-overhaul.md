# 课程体系大改

## 问题

1. **终点不诚实**：45 课 / 352 词 / 40 语法点被标成「站内 C1 桥接」。这只够扎实 A2、刚进 B1。
2. **课太薄**：几乎每课 4 张讲解、6 道题，时长 12–20 分钟，只够扫过句型，不够形成反应。
3. **掌握门槛过低**：`UNLOCK_SCORE = 65`，带错也能推进。
4. **路径跳跃**：连接词、原因、条件、意图挤在少数课里；느데 / 니까 / 으면 / 아 보다 / 으러 没有专课；慢速新闻出现时叙述工具还没练够。
5. **母语者课过早当终点**：敬语、软化、拒绝是 B1–B2 语域入口，不是母语者毕业。

## 原则

- 站内核心路径终点改为 **扎实 A2 / B1 入口 + 语域桥接**，C1+ 只留在长期作品集。
- 先修仍线性：上一课必须达到掌握分才能建议下一课。
- 旧课 **id 不变**，只改 `order` / `milestone` / 厚度，避免打坏本机 SRS。
- 新课使用 `l46+`。
- 学习引擎（workspace / SRS / quiz）不重写。

## 新掌握标准

- `UNLOCK_SCORE = 80`
- 每课至少 6 张讲解、8 道题（含听辨、填空、产出）
- 时长 16–32 分钟

## 60 课轨道

| 阶段 | 课序 | 真正水平 | 内容 |
|---|---|---|---|
| m0 文字与声音 | 1–8 | A0 | 原 6 课 + 音节流利 + 双收音 |
| m1 礼貌生存 | 9–20 | A1 | 原生存课 + 을/를 + 도/만/부터/까지 |
| m2 连续日常 | 21–43 | A2 | 原连续课 + 는데/니까/으면/면서/아 보다/으러 |
| m3 叙述与材料 | 44–53 | B1 入口 | 被动使动、让步、推测、新闻/复述/职场 |
| m4 语域桥接 | 54–60 | B1–B2 入口 | 敬语、软化、拒绝、半语、书面、整合 |

最终课仍是 `l30-native-capstone`。
