# 学习轨迹修复

## 现在实际怎么走

1. 入门：目标 + 语音 + 键盘，然后进 `l01`。
2. 工作台 `recommended`：到期 SRS(100) → 图书馆缺口(96) → 下一课(路径 90 / 自学 65；库未满 64) → 错题修复(86) → 最弱能力(80) → 材料(m2+ 88，更早 66) → 母语者(m3/m4 70，m2 60，更早 52)。
3. 核心路径解锁：上一课 ≥ 80%，**并且**当前阶段图书馆门槛已满。韩文页、词汇页、语法页、材料不再是可跳过的旁路。
4. 护照仍比主线更严：主线把人带到扎实 A2 / B1 入口；护照要额外的材料、输出和检查点。两者不再互相假装。
5. 输出关卡覆盖连接、新闻、复述、转述、观点、职场、半语和书面。

## 缺口（修复前）

- 主线不强制韩文实验室，m1 粒子课可以在字母未入册时开始。
- 词汇/语法是旁路，推荐里永远排在下一课后面。
- 材料在路径模式下优先级 58，几乎不会成为“今天必须做”。
- 母语者任务 52 分，进不了六条推荐。
- 错题修复跳综合测验，未达标课的弱项进不了题池。
- 课页写“旁路预览”，`applyLessonCompletion` 却只看先修，预览可刷主线。
- 路径 Compass / 路径 CTA 仍把人送进被挡的下一课。
- 自学/路径只改优先级，不改下一课是谁。
- 护照和路径脱节：可以 60 课全过，护照仍停在 A0。

## 修复

1. **阶段图书馆门槛**（不改先修图，`isLessonUnlocked` / validate 遍历仍成立）
   - m0 第 4 课起：韩文掌握 ≥ 12
   - m1：韩文 ≥ 28，词汇 ≥ 16（对齐 A0+ 字母）
   - m2：韩文 ≥ 28，词汇 ≥ 40，语法 ≥ 8，材料 ≥ 1
   - m3：以上 + 词汇 ≥ 80，语法 ≥ 16，材料 ≥ 3
   - m4：以上 + 词汇 ≥ 120，语法 ≥ 24，材料 ≥ 4，母语者证据 ≥ 4
2. 门槛未满时：
   - 工作台把对应库任务提到 96，下一课降到 64
   - 课页按旁路预览处理
   - **写入层对韩文/词汇/语法同样只记 preview**，不能把预览刷成 `completedLessons`；已在主线里的课不会被回写剥掉
   - 材料/母语者证据仍走推荐 96 + UI 预览，不改 `isLessonUnlocked` 先修图
   - 路径 CTA / Compass 先送去补库
3. m2 起把已解锁材料升到 88；m0/m1 有可做材料时升到 66。
4. 母语桥接：m2=60，m3/m4=70，native 目标仍 76。
5. `GATE_PASS_SCORE` 与主线对齐为 80；课评估 `overallPassed` 也对齐 `UNLOCK_SCORE`。
6. 综合测验把未达标课里已经错过的 drill 放进题池；若弱项集中在一节未完成课，修复任务回该课。
7. 图书馆任务的完成态看计数，不看“今日已点完成”。
8. 输出关卡加到新闻、转述、抽象讨论、背景句、职场、半语、书面邮件，以及咖啡店 / 问路 / 购物生存课。
9. 听辨全跳过只保存练习，不写入核心路径；至少答对一题听辨或听写才能掌握。
10. 作品证据无效时，日常读档和备份导出都会回滚该课；没有作品记录的旧存档仍保留。
11. 首次访问：hero、指南针和播放队列都进 `/onboarding`。
12. 到期复习压过路径 CTA / Compass 下一课；有到期卡时下一课优先级降到 70。
13. 材料/母语者门槛写入主线（入册计数）；说话课记听辨+语用，不再记成母语者层。
14. 检查点必须已有学习痕迹，并且证据里要有韩语。
15. 路径上未开的课点进去先去补库或前置课，而不是伪装成可播放。
16. 沉浸页默认打开下一份已解锁未完成材料，队列把可完成项排在前面。
17. 入门必须点过试听（设备没声音时可跳过）。
18. 到期卡 ≥ 8 时下一课退出今日六条推荐；已掌握课若有 3 道以上回潮题，会生成回炉任务。
19. 首次访问今日歌单只放入门，不再列出第一课。
20. `speaking` 课只要有听写/听辨题，跳过音频就不能掌握。
21. 沉浸先修未满时不开放原文、朗读、听写原句和输出存档。
22. 材料写入门槛与护照一样，只数有效证据，不数空的 completedMaterials。
