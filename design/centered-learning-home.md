# 首页返工：居中的学习入口

历史方案：本版被用户指出仍不美观。当前实现以 [learning-note-home.md](learning-note-home.md) 为准；不恢复本文的粗重双行标题和分栏入口面板。

## 约束与构图

保留精简导航、独立韩文字图片、不均匀贴法和内容自然撑开的高度。撤销被用户否定的整页左右分栏，不恢复早期 550px 大封面或四角贴片。

- 色彩：纸白 #FCFCFA，墨黑 #222222，钴蓝 #3155E7，淡紫 #D8CCF0，柠檬黄 #F2EB98，橘红 #FF784F。
- 字体：系统 sans；标题约 34–60px、600–650 字重，两行同色；正文 13–15px，入口 16–20px。韩语细读保留原字体。
- 首页以一条居中的阅读轴组织标题、说明、主按钮。按钮自身严格居中，学习用时放进下方辅助文字。
- 主标题左侧仅一小簇 안녕/ㅋ，位置与大小有差异；手机重新放到标题上缘与右侧，不预留大块装饰空间。
- 两个入口共用一个约 680px 宽的面板，以内部细线区分；少量文字图贴在面板边缘，形成一组完整内容。
- 手机入口为紧凑纵排。保留 44px 触控目标、键盘焦点、夜间对比度与无横向溢出。

```text
           Kirina       今日  学习  练习       我的

              안녕       把韩语，
                  ㅋ     学进日常。
                  看懂一个字，听懂一句问候。
                    每天一点，离韩语更近。
                         [开始学习 →]
                    三分钟，从第一句开始。

             ┌─────────────────────────┐
             │ 学一点新的  조금씩 │ 把学过的记牢 │
             │ 课程、字词与听说   │ 复习、错题… │
             │ →                │ →      다시 │
             └─────────────────────────┘
```

## 实现前复核

此前失败来自页面内容被拉到两侧，装饰与文字之间没有共同的构图边界。本次先建立中央主体，再通过局部贴片打破机械感；入口虽有两个目的地，但共享面板并紧跟主操作。取消额外韩文标签、独立标语区和专为图片设置的高度。艺术只占局部，不拉开阅读路径。

清理首页旧的双栏、四角、生活拼贴选择器，保持唯一的当前首页样式。现有学习状态、首访流程和 URL 导航继续复用。

## 实现与验收

首页内容改为 760px 以内的居中主体，共享入口面板最大 680px；导航最大 960px，页脚文字居中。主按钮单独居中，用时放在辅助行，不会把按钮挤偏。入口面板在 560px 以下改为纵排，文字贴片随断点重新定位。删除首页旧的双栏、四角和整幅拼贴样式，避免多轮覆盖继续影响当前构图。

人工检查了 1440、768、390、320px 的截图和手机夜间主题。平板初稿的 ㅋ 曾靠近说明文字，现已改为相对标题高度定位；手机使用独立位置。最终桌面入口底边约为 627px，手机约为 625px；标题、主按钮、两个入口在所检验的首屏内可见，贴片没有遮挡阅读和操作区域。

本次验证：内容校验、ESLint、生产构建（含 TypeScript 与 79 个静态页面）通过；九个栏目、六种宽度的 30 组布局，以及材料导航、历史返回和草稿恢复回归通过。单独检查首页主按钮与主体中线对齐，三个入口分别跳转到入门、学习与练习。宽屏和手机生产截图为 `output/playwright/center-home-wide.png`、`output/playwright/center-home-narrow.png`，已同步到 PWA 截图目录。
