# Kirina Korean · 韩文字碎片与简洁留白

这是当前视觉约定。2026-09-09 用户明确要求：碎片是单个或几个文字的小图片，不是生活场景。此前的大幅拼贴与景物画不再用于页面。

## 视觉原则

艺术资产为六张独立韩文字贴片：ㅋ、ㅎ、안녕、한글、다시、조금씩。每张只有一个字母或一个短词，真实透明背景、粗体印刷字形、轻微纸边。它们以约 45–220px 的独立区域点缀标题与入口附近，不共用大幅画框。透明画布内实际文字尺寸更小，摆放需以实际可见图形为准。界面以留白和清晰文字支持学习。

- 页面 #FCFCFA，正文 #222222，主操作 #3155E7。
- 辅助色 #FF784F、#F2EB98、#D8CCF0 用于贴纸与栏目；正文不使用浅色低对比文字。
- 系统 sans 承担标题、正文和控件，粗细与字号区分层级；韩文细读保留 Noto Serif KR。
- 按钮 8px、内容面 12px、栏目图像 16px 圆角；阴影仅用于弹出菜单。
- 不再叠加电影滤镜、字幕遮罩或纹理；展示图片使用 object-contain，避免裁切韩文字。
- 默认白昼，另有蓝调、暖阳、夜行。保留 yuan / yue / qing / ye 存储键兼容旧设置，主题不影响学习结构。

## 页面结构

首页是一张居中的韩语学习笺：안녕/ㅋ 组成顶部的文字主视觉，中文标题减轻到 450 字重、取消过紧字距并优先单行排布。说明只保留一句，主按钮为较小的圆角胶囊，首访不重复显示两次三分钟。学习与练习进入下方最大 520px 宽的两行开放目录，取消卡片外框和左右分栏；手机说明放在入口标题下方。少量文字图贴近目录局部，避开文字和点击区域。首页导航采用小圆点表示当前位置，页脚仅保留轻量品牌署名。首访引导至三分钟入门，回访行动由 workspace 计算。

顶层导航只有「今日、学习、练习」，工具入口为「我的」。课程、字词、听说集成在学习空间；复习、错题、测验集成在练习空间；计划、记录、偏好、外观与数据工具集中在个人空间。栏目选择写入 URL，旧链接继续有效。品牌标记为 ㅋ 贴纸，全站不叠加浮动继续按钮。

学习空间只展示一个标题与一对小文字点缀，嵌入内容不重复展示大标题、装饰与跨模块目录。课程默认只显示近期六课，完整阶段与长期路线按需展开。手机保留缩小的文字点缀；首页贴片随断点调整，不遮挡文字、按钮或导航，也不紧贴屏幕边缘。键盘导航、44px 触控目标、正常/错误/空白/成功状态与减少动效设置适用于所有主题。

## 资产与维护

六张 letter-* 原始 PNG 及透明 WebP 保存在 public/assets/generated，由 LetterFragment 统一展示，ArtScene 按模块选择两个互相分离的文字片。旧拼贴保留为源资产记录，不再由页面组件加载。图标另有常规与 maskable 的 192/512 像素版本。登记见 src/data/visuals/assets.ts 与 manifest.ts。

当前首页设计与验收见 [learning-note-home.md](learning-note-home.md)。上一版居中方案见 [centered-learning-home.md](centered-learning-home.md)，文字资产、提示词与此前版式记录见 [scattered-fragments.md](scattered-fragments.md)。空间整合记录见 [quiet-learning-spaces.md](quiet-learning-spaces.md)，首轮视觉设计见 [seoul-sticker-redesign.md](seoul-sticker-redesign.md)。scripts/imagegen-jobs.json 保存完整提示词；准备同名 PNG 后，可运行 node scripts/prepare-imagegen-assets.mjs 重新导出网页资源。旧景物画保存在 Git 历史。

图片文字仅作美术表达，使用空 alt 与 aria-hidden，不进入朗读和键盘焦点；pointer-events: none 保证学习操作可点击。课程中的韩文必须使用可复制的 DOM 文本。
