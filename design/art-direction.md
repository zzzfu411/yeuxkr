# YEUX KR - 纸本美术与信息架构

Kirina Korean 的界面属于 **YEUX KR**：它与 yeuxark.com 是同一间工作室写下的纸本作品，但服务于完整、可反复使用的韩语学习流程。产品名始终是 **Kirina Korean**；YEUX KR 是界面家族与视觉署名，不替换 manifest、页面标题或产品身份。

一句话：**把韩语学习摊开在一张有纤维、墨迹和使用痕迹的纸上。**

界面不是杂志封面，也不是 SaaS 仪表盘。它用安静留白、日期行、手写路标和少量朱印组织学习任务，让路径、复习、韩文、课程与沉浸材料像一册长期使用的个人纸本图集。

---

## 1. 视觉原则

- **纸是空间，不是卡片皮肤。** 页面、导航、抽屉和学习面共享连续纸面；区块主要靠留白、细墨线、纸色层次与排版区分。
- **墨是主要界面色。** 大部分信息使用石墨黑和稀释墨；唯一鲜明色是褪色朱印 `--seal`，面积保持克制。
- **手作但清楚。** 纸纹、暗角、胶带、毛边和印章提供触感，文字层级、焦点状态和操作反馈仍须准确易读。
- **近乎无圆角。** `--radius: 3px`；圆形仅留给主题色点、播放状态或本身为圆形的图标。
- **柔软的深度。** 使用扩散纸影和轻微 sheen，不使用硬偏移阴影、3px 深色框或积木式高饱和按钮。
- **图像来自韩语学习桌。** 韩纸、砚台、墨刷、活字块、手写 Hangul、首尔街巷与咖啡馆都可以出现；不借用鱼仔作为 Kirina 吉祥物。

明确排除旧的 KAZAM / Player Desk 语言：没有唱机式常驻侧栏、歌单隐喻、黄色 CTA、热粉播放键、DM Sans 900 标志、厚框 neo-brutal 控件或 OLED 黑底。播放器若出现，只是材料页里的安静学习工具，不主导应用骨架。

## 2. 四种纸色

主题切换使用纸色点或短手写标签，提供完整的四种选择。切换主题只交换纸、墨和由它们推导出的表面色，不改变信息架构。

| 主题 | 核心纸色 | 墨色 | 气质 |
|---|---|---|---|
| 原纸（默认） | `#d8d3cc` | `#1b1815` | 温和灰纸、最接近 yeuxark.com |
| 月白 | `#d3d6da` | `#17191c` | 冷静、轻微蓝灰 |
| 淡青 | `#cdd6cf` | `#18201b` | 很浅的青瓷纸色 |
| 夜墨 | `#2a2733` | `#ece8df` | 深紫墨纸，而非纯黑仪表盘 |

基础 token：

```css
--paper: #d8d3cc;
--paper-hi: #e7e3db;
--paper-lo: #c6c0b6;
--paper-edge: #b4ada1;
--ink: #1b1815;
--ink-soft: #3b352f;
--seal: #8c3a2c;
--radius: 3px;
--line: color-mix(in srgb, var(--ink) 34%, transparent);
--shadow: 0 16px 34px rgba(46, 39, 31, 0.16);
```

同时保留 `--tape`、`--shadow-soft`、`--sheen`、`--shade` 与 `--wash-1` / `--wash-2` / `--wash-3`。静音文字、分隔线、悬停底色和输入表面优先用 `color-mix()` 从当前 `--paper` / `--ink` 推导，使月白、淡青与夜墨都保持相同层级。夜墨的阴影、纸纹和边缘仍然可见，绝不退化成 void black。

## 3. 字体与语言标记

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文与手写界面 | LXGW WenKai Screen | 中文、拉丁正文、导航和表单；自托管 WOFF2，`font-display: swap` |
| 毛笔标题 | Ma Shan Zheng | 封面标题、章节题签、少量印章式标题 |
| 英文批注 | Caveat | eyebrow、日期旁注与英文 scribble |
| 韩文阅读 | Noto Serif KR | 大音节、课程封面、例句和需要细读的韩文 |

回退字体依次考虑 `楷体` / `KaiTi` 与系统 serif。双语标签写成安静路标，例如 `복습 · 复习`、`Immersion · 몰입`；英文只作辅助批注，不把页面做成全大写控制台。字距保持自然，不使用负字距或粗黑 logo 塑造品牌。

## 4. 纸面构成

全局纸面由三层组成：底部真实或生成的纤维纹理，中层低透明 grain，顶部柔和 vignette。纹理不能降低韩文笔画的清晰度，也不能随滚动出现明显接缝。

纸面容器可通过共享 SVG `feTurbulence` / roughen filter 获得轻微毛边。filter 只作用于装饰边缘、胶带或插画框，不应让正文持续抖动。常用表面包括：

- 半透明胶带压住插画角或题签；胶带颜色由 `--tape` 提供。
- 细墨线和略有偏差的下划线，用于日期行、列表和导航当前项。
- 很淡的 Hangul 朱印、课程编号章或完成章；朱红不承担大面积背景。
- `--shadow` / `--shadow-soft` 形成纸张离桌面的柔影，不使用硬偏移黑影。
- 小范围 `--sheen` 与 `--shade` 表示纸面受光，不使用彩色渐变装饰。

## 5. 图像语言

生成资产必须看起来属于同一本韩纸册：低饱和石墨与水墨、可见纸纤维、留白充足、稀少的朱印。图中不出现水印、UI 截图、可读的生成式乱码或无关人物。

核心图像组：

- **Cover / Hero：** 韩纸、砚台、活字或折纸 Hangul 的安静静物，第一屏只保留一个明确视觉中心。
- **Hangul Studio：** 墨石、笔触、拆开的韩文字块和练习纸，强调字形构造而非科技实验室。
- **Lesson / Path / Workspace：** 摊开的纸页、日期索引、压角胶带与路径记号，像个人学习图集。
- **Immersion：** 首尔街巷或咖啡馆的纸上淡彩 / 墨洗场景，支持听读内容而不抢夺文本。
- **Empty states：** review、mistakes、immersion 各自有小幅手绘纸上插图；空队列表达停顿与完成，而不是灰色占位框。
- **Stamp / OG：** 朱印 PNG 可复用为低透明装饰；社交图延续同一纸、墨、Hangul 静物语言。

每项生成资产同时保留 PNG 源图与用于页面的 WebP，提交在 `public/assets/generated/`（或 `public/assets/img/paper/`），并在 `src/data/visuals/assets.ts` 与 `src/data/visuals/manifest.ts` 登记。生成出来的图必须有实际页面引用。

## 6. 壳层与导航

桌面壳层是一张连续纸面：左侧或顶部放小型 YEUX KR 署名，主导航使用 `한국어 · 中文 · EN` 式手写路标；右侧放主题色点与必要的学习数据入口。导航不是相连厚边 tab，也不使用独立浮卡包住每一组链接。

首页是个人学习 hub：

```text
YEUX KR / Kirina Korean                    原纸  月白  淡青  夜墨

오늘 · 今日                                   2026.08.30
下一步学习题签 + 一幅韩纸静物
------------------------------------------------------------
日期 / 编号      学习路径与到期队列                  状态朱印
日期 / 编号      韩文、复习、沉浸入口                手写批注
```

封面保持安静：纸纹、一幅手作插画、极少界面 chrome，并在首屏边缘露出下一段内容。Hub 用 eyebrow、日期列表和手写 signpost 组织扫描；任务可密集，但避免 dashboard 指标卡阵列。

移动端收紧留白并把导航收进纸面菜单；不加入底部迷你播放器。所有点击目标、焦点环和当前状态在四种主题下都必须清楚。

## 7. 学习页面的一致性

- **Onboarding：** 像填写一张入册纸笺，用细线字段、编号步骤和一枚完成朱印。
- **Hangul：** 大字保持 Noto Serif KR；字母组合、发音和书写练习放在带纸纹的开放工作面。
- **Learn / Lesson：** 课程目标、讲解、听读与练习沿一条纸上阅读流展开，操作按钮使用墨线与轻 wash。
- **Review / Mistakes：** 到期卡与答题反馈保留明确状态；错误用朱印短促提示，不以大红块惩罚学习者。
- **Immersion / Player：** 场景插画、逐句文本与安静的音频控制共处；播放控件是嵌入内容的工具，不成为全站音乐播放器。
- **Completion / Empty：** 使用对应手绘插图、日期和短批注，仍提供清楚的下一步。

Button、input、surface、modal 和 focus ring 都从统一 paper token 派生。熟悉的操作优先使用图标并提供 tooltip；主要命令可用图标加短文本。朱红只用于当前、完成、错误或印章语义。

## 8. 实施边界与验收

这次重构只改变美术、壳层、排版、主题与视觉资产，**不改学习逻辑**。课程数据、路径推荐、SRS、quiz engine、mistake 写入、workspace model、speech 与进度持久化继续使用现有契约。

验收标准：

1. Shell、nav、home、onboarding、hangul、learn、review、immersion 与 player 在原纸、月白、淡青、夜墨中属于同一种纸本语言。
2. 页面没有 KAZAM / Player Desk 遗留的黄色块、热粉按钮、硬偏移阴影、厚重 navy 边框或纯黑暗色。
3. 生成的 hero、场景、空状态、印章和 OG 资产已登记、已提交且确实被页面使用。
4. 四主题均保持可读、可聚焦、可操作；移动端无溢出或遮挡。
5. `validate`、TypeScript、测试与 lint 通过，学习流程和数据断言不因视觉重构而改变。
