# 更安静的学习空间

这轮目标：减少同时出现的功能入口，让艺术承担更多识别作用。保留首尔街景、韩文贴纸、纸张剪贴的原创视觉体系。

## 页面结构

```text
Kirina          今日  学习  练习          我的
今日：一句问候 + 继续学习 → 两张插画入口 → 首尔生活拼贴
学习：课程 / 字词 / 听说 → 当前内容
       字词：韩文 / 词汇 / 语法
       听说：听读 / 表达
练习：复习 / 错题 / 测验 → 当前练习
我的：偏好 / 计划与记录；外观和数据工具集中在这里
```

只加载当前内容，栏目选择写入 URL，支持刷新、前进与后退。旧课程与材料链接继续有效。嵌入空间的内容只保留功能动作，不重复展示页面标题或跨模块目录。切换栏目停止语音。

## 视觉

- 白色 #FCFCFA，墨黑 #222222，钴蓝 #3155E7；贴纸使用柠檬黄 #F2EB98、橘红 #FF784F、淡紫 #D8CCF0。
- 沿用项目本地字体与韩文字体。中文负责清晰的操作说明，韩文负责少量标题和美术表达。
- 首页保留一个主要按钮、两个图文入口。新增书店、练习贴纸、市集和唱片街角四张原创资产，使用 WebP 展示，保留 PNG 源文件。
- 大面积留白、轻分隔线、44px 最小触控目标。小屏不隐藏空间封面，缩小为可辨识的插画。

## 自查重点

简约应减少选择数量，而非仅把原来所有按钮塞入抽屉。学习与练习确实在同一空间切换；设置与记录有明确归属。图片数量增加后仍保持一个视觉焦点，不增加同等权重的行动按钮。

验证：移动与桌面布局、所有栏目切换与 URL 历史、材料草稿、原有学习证据和备份重置流程、静态检查与生产构建。

## 实现后的视觉复核

- 首页从任务与统计集合收敛为一个学习动作、两个入口、两张生活拼贴；在 390px 下保持一行主导航。
- 学习空间先展示标题、封面和局部栏目。课程默认只显示当前阶段近期六课；「展开全部课程」仍能访问全部 60 课。
- 手机课程默认页由约 8,605px 缩短为约 2,234px。阶段要求和长期路线改为按需展开，保留课程前置条件和真实进度。
- 个人空间在小屏保留“学习数据”文字；外观菜单锚定整个工具区，避免从左侧溢出。
- 空间标题与封面预渲染，封面优先加载；其余内容按栏目加载。旧路径、材料参数和锚点仍然有效。
